# 版本与源码边界

## 本次升级后的观测

用户随后授权将 Pi 更新到 **4.29.3**。新版本快照与 12 项通过的接口探针已新增，旧 4.29.1 快照不覆盖；详见 [升级记录](UPGRADE-2026-10-31.md)。这仍然不是永久版本锁。默认探针留作历史回归，使用新快照请显式指定路径。

## 兼容性策略

M1 本地验证使用新建的 Python 3.12.13 虚拟环境与实际安装的 AstrBot 4.29.3 SDK。已读取发行包元数据，确认 `Requires-Python: >=3.12`；产品测试通过实际 Context / PersonaManager 方法、ProcessStage、配置 schema、权限过滤与元数据加载器运行离线场景。三组保存快照另有 AST 接口回归。

本轮没有重新连接 Pi 核验实际服务版本；最近的 4.29.3 部署记录不能替代实时核验。4.29.1 与固定研究提交只验证保存的接口方法，不代表已在其完整 SDK、所有插件或真实平台上运行当前产品。其他版本兼容性未知。

`metadata.yaml` 不填写未经完整测试支持的版本范围；运行时对必要 Context/人设能力做显式检查，缺失时告警并关闭自主插话。SDK 调用或响应不符合契约时该次尝试失败关闭，不回退到正常 Agent。没有给 Pi 安装、升级、降级或设置版本锁。

**4.29.1 是交接时已验证的回归基线，不是永久适配目标。Pi 上的 AstrBot 可能继续更新。**

1. 实施适配、部署前与升级后，只读核验实际服务所用解释器/发行包版本、Python 要求和所需 API；不要从系统 Python 或非 Git 工作目录猜版本。
2. 依赖公开稳定接口，将差异集中在小型适配层。兼容性不能只按版本号推断；验证配置、事件、模型响应、发送与静默控制流。
3. 当前目标 SDK 版本固定在开发测试环境以便复现，但不给 Pi 加版本锁，也不自动升级或降级服务。
4. 保留旧回归快照；新增明确版本/来源/hash 的快照与测试结果。未测试版本标注未知。
5. 相关能力缺失时禁用自主插话并给出明确告警，正常 @ 与命令不受影响；不悄悄换路由或模型。
6. 当前部署信息暂不可得时，先推进离线实现，将实际版本适配保留为部署门槛，不强迫反复询问或宣称兼容。

## 交接时的实际观测

在交接时，Pi 的 AstrBot 用户服务入口解析到的独立 uv 工具环境中，`importlib.metadata.distribution("astrbot")` 返回：版本 **4.29.1**，`Requires-Python: >=3.12`。其工作目录 `~/astrbot` 不是 Git checkout，因此没有给它编造提交号。

`research/snapshots/deployed-4.29.1/` 保存三个只读源码文件和 SHA-256；不包含数据库、模型凭据、运行配置或聊天数据。默认探针读取这一组；文件夹名 deployed 只表示当时采样来源，不表示 Pi 现在必定仍是这个版本。

## 原研究基线

`research/snapshots/research-master/` 来自固定提交 `3d92821ad9d90df33fc242e7b159a3260075eb2c`，保存原始 Git blob hash。对应证据和更多源码链接保留在 `docs/archive/`；不把它称为当前最新 master。

对两版 AST 去除格式差异后比较：

| 方法 | 比较结果 |
| --- | --- |
| `Context.llm_generate` | 一致 |
| `Context.get_current_chat_provider_id` | 一致 |
| `PersonaManager.get_persona` | 一致 |
| `ProcessStage.process` | 不完全一致：研究版多了 session-waiter 分派；目标 4.29.1 不含这段 |

不可据这四个方法推断整个 AstrBot 完全兼容。插件实施还应核对事件装饰器、配置 schema 和消息结果类型。实际目标以实施/部署前新核验的运行版本为准；4.29.1 保留作回归。支持更多版本需各自验证，不应把此基线硬编码为永远的最高或唯一支持版本。

## Mac 环境

Mac SSH 默认 `python3` 为 3.9.6；只够运行本仓库标准库交接检查。`/opt/homebrew/bin/uv` 已发现，版本 0.11.32。实际 SDK 开发环境由 uv 在本项目创建满足目标 SDK 要求的 `.venv`；4.29.1 的已知要求是 Python >=3.12，新版本须重核，不改系统默认 Python。
