## 版本固定与依赖处理

原 uv 工具要求曾是 `astrbot==4.29.1`，普通 upgrade 因此只更新依赖。本次以 `astrbot@latest` 重新安装后，工具 receipt 的要求已变成仅 `astrbot`，不再固定旧版本。

稳定 AstrBot 新依赖的 OpenTelemetry SDK 要求一个带 beta 版本号的 semantic-conventions 包。只对该依赖开放 prerelease，AstrBot 本体仍选择稳定版；不是全局改成接受所有预发布版。最终执行命令为：

```bash
uv tool install astrbot@latest --python 3.12 --force \
  --prerelease disallow \
  --prerelease-package opentelemetry-semantic-conventions=allow
```

本条仅记录已执行操作，不意味着本地 agent 应自行再次安装、重启或改变 Pi。未来版本按实际 metadata 与兼容性重新核验。
