# 验收清单

以下是待实施验收，不是已通过测试。

## M1：离线插件

- [ ] 项目开发 Python >=3.12，依赖不污染全局环境。
- [ ] 插件默认关闭、shadow 默认开启、空白名单不匹配任何群。
- [ ] 插件开关与全局 AI 开关均生效。
- [ ] 普通 @、唤醒词、命令、私聊保持原行为，不多一次模型调用。
- [ ] 自发言和重复事件不会造成循环。
- [ ] 独立 `<noreply>` 静默；正文引用标签不会误删；混合控制动作、空/超长输出失败关闭。
- [ ] 错误 role、工具调用、非文本响应和异常不外发。
- [ ] 一次机会只调用一次假模型；无 stream、无 tool loop、无隐式新建会话。
- [ ] 按物理群隔离，发送者隔离配置不会把同群记忆切碎。
- [ ] 窗口条数、单条长度、总背景预算和去重信息有界。
- [ ] 沉默后仍保留前文；当前消息不重复；shadow 假想回复不进入真实发言窗口。
- [ ] 同群单请求，忙时只记录；无逐条请求积压。
- [ ] 超时/异常/取消后释放状态，重置/关闭/卸载/显式唤醒使旧结果失效。
- [ ] silent/invalid/shadow 分支无发送结果；live 正文只生成普通文本结果。
- [ ] 不使用 stop_event 表示沉默，不重新 yield ProviderRequest。
- [ ] 管理员清空插件记忆入口有权限验证，正常 /reset 的边界有文档。
- [ ] 产品测试、两版接口探针、交接完整性和 git diff --check 真实执行通过。
- [ ] README 和状态说明明确：没有正常会话双向历史统一，没有真实模型与平台验收。

## M2：需用户另外放行

- [ ] 确定测试机器人/群、人设、Provider 和实际模型调用授权。
- [ ] shadow 收集误插话、过度沉默、遗漏与协议异常的真实样例。
- [ ] 用户批准单群 live 和必要安装/重启。
- [ ] 真实收件、关闭开关、迟到结果丢弃与 @/命令回归通过。
- [ ] 失败不自动重试发送或转为另一条模型请求；记录费用与日志边界。

## M3：后续整合

- [ ] 正常 @ 请求可以通过临时上下文理解自主发言，去重且不污染持久历史。
- [ ] 人设同步遵守实际选择优先级。
- [ ] 如确有必要，再实现可验证的持久化或单 pending 快照合并。
