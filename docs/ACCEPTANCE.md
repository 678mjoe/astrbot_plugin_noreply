- [x] 核验本地所选目标 SDK AstrBot 4.29.3 的发行包元数据、所需 API 与 Python >=3.12 要求；项目内 Python 3.12.13 环境满足要求。Pi 实时核验保留为 M2 门槛。
- [x] 4.29.1 仅作已验证回归基线，不锁定/降级/自动升级 Pi；本地 4.29.3 SDK 和三组保存接口有实际测试，其他版本标为未知。
- [x] 插件默认关闭、shadow 默认开启、空白名单不匹配任何群。
- [x] 插件开关与来源配置中的全局 AI 开关均生效。
- [x] 普通 @、唤醒词、命令、私聊在离线事件与实际 ProcessStage 中保持原路由，不多一次自主模型调用。
- [x] 自发言过滤、重复消息 ID 去重，不造成自主请求循环。
- [x] 独立 `<noreply>` 静默；正文引用标签不会误删；混合控制动作、空/超长输出失败关闭。
- [x] 错误 role、工具调用、流式分片、非文本响应和异常不外发。
- [x] 一次机会只调用一次假模型；无 stream、无 tool loop、无隐式新建会话。
- [x] 按物理群隔离，发送者隔离配置不会把同群记忆切碎。
- [x] 群状态容量、窗口条数、单条长度、完整 JSON 背景预算和去重信息有界。
- [x] 沉默后仍保留前文；当前消息不重复；shadow 假想回复不进入窗口。
- [x] 同群单请求，忙时只记录；无逐条请求积压。
- [x] 超时/异常/取消后释放状态；清空、关闭、卸载、显式唤醒使旧结果失效。Provider 吞掉取消后返回的迟到正文也被拒绝。
- [x] silent/invalid/shadow 分支无发送结果；live 正文只生成普通文本结果。
- [x] 不使用 stop_event 表示沉默，不重新 yield ProviderRequest。
- [x] `/noreply_clear` 由真实 SDK 管理员过滤器及入口权限检查保护；普通 `/reset` 只使旧生成失效，不清空插件窗口。
- [x] 产品测试、三组接口探针、交接完整性、静态检查和 git diff --check 真实执行通过。
- [x] README 和状态说明明确：没有正常会话双向历史统一，没有真实模型与平台验收；本地发送观察不代表送达。
